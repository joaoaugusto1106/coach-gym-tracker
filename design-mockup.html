Design direction · v1

Beat Last Time

Seven screens, light and dark, at the size you'll actually hold. This is the visual system before any feature code — the palette, the type, the glass layer, the way a set gets logged. React to it and I'll adjust, then build stage 1.

  • Green — progress, "go", add load
  • Amber — a PR
  • Red — under-recovered, back off

Type is the system font stack (renders as San Francisco on your devices) in three roles — big tabular numbers for weights, 17px semibold for controls, 11px tracked caps for labels. No downloaded font, no Inter, no emoji icons, no purple. Glass sits only on the tab bar and nav bar; every list and card underneath is opaque and full-contrast.

What this deliberately isn't

  • No purple/indigo, no gradient buttons, no glow, no glassmorphism on content — glass is only the tab bar and nav bar.
  • No downloaded webfont. System stack renders as SF on your iPhone and Mac, nothing to license or embed.
  • No SF Symbols — a single custom stroke icon set at one weight.
  • Three colours with one job each. Everything else is ink on a near-white or true-black ground.
  • True black in dark mode — reads right on the iPhone OLED, saves battery in the sauna.

Tell me before I build stage 1

  • Green — is this saturation right, or push it deeper / more olive?
  • Dark mode on true black, or a dark grey ground like Fitness uses?
  • Set entry: steppers + RIR segments as shown, or do you want a bare number pad?
  • Is "Beat Last Time" a good name for the app itself, or keep it plain?
  • Any screen missing, or anything here too busy for mid-set use?

Once you're happy, stage 1 is logging + local storage: create a session, add exercises, weight × reps × RIR per set, saved to the phone and still there after a reload.
